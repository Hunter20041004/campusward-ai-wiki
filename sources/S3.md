# S3 小山的搜課與排課方案產生（orb.ts）

[原文](https://raw.githubusercontent.com/Hunter20041004/campusward-nccu/5d0a4637d66392a3155a4f7a80b7b9eaebfc5b49/apps/web/src/ai/orb.ts)

- 一次需求最多兩次模型呼叫；第一次需要搜課時，本機先查，再交回第二次模型
- 最多採用四組搜尋，每組最多二十門；星期詞會轉成搜尋條件
- 此檔回傳變更方案與回答，實際套用另交給引擎與畫面狀態處理

限制：最多兩次只指這個排課函式，不能推論全部 AI 功能或整段對話的總呼叫數；只讀此檔不能證明套用、備份及復原已完成，也不能說模型找遍全部課程。
