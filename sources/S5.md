# S5 依課綱回答與引用過濾（answer.ts）

[原文](https://raw.githubusercontent.com/Hunter20041004/campusward-nccu/5d0a4637d66392a3155a4f7a80b7b9eaebfc5b49/apps/web/src/qa/answer.ts)

- 模型只收到問題與傳入的課綱段落，這個函式沒有傳課表、身分或修課紀錄
- 提示要求只依段落回答，缺資料就說課綱沒有寫，課綱文字要當資料而非指令
- 回覆以本機欄位規則檢查，引用課號去重後只保留提供過的課號

限制：過濾引用課號不等於逐句查證答案，仍可能錯解、漏引或出現無來源說法；程式允許空 citations，也可能過濾後變成空陣列，不能保證每次回答都有有效引文；這個檔案接收已找好的 context，沒有證明上游採用 BM25、向量或哪種搜尋法。
