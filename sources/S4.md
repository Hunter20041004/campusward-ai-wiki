# S4 排課方案的規則檢查（validate.ts）

[原文](https://raw.githubusercontent.com/Hunter20041004/campusward-nccu/5d0a4637d66392a3155a4f7a80b7b9eaebfc5b49/packages/engine/src/ai/validate.ts)

- 檢查衝堂、資格、非同步上課、學分範圍、實習天數與空堂日
- 阻擋問題放在 violations，待人工確認的資格放在 warnings
- valid 只取決於 violations 是否為空，有 warnings 仍可能 valid

限制：此檔是檢查函式，不負責實際套用或自動備份；可設定的學分與空堂條件要由呼叫端提供，不能說此檔已自動套用所有學校規則；未知且未鎖定的課程在這個函式會被略過，課程真實性與移除鎖定課仍需其他流程檢查。
